## Why

Нужен технический фундамент личного трекера, которым можно пользоваться на Android и macOS с одной учётной записью и синхронизацией данных. Активности будут сильно различаться по данным и интерфейсу, поэтому их нужно подключать как самостоятельные модули, не закладывая все будущие функции в первую итерацию.

## What Changes

- Добавить устанавливаемое приложение для Android и macOS с входом, базовой навигацией и экраном профиля.
- Добавить локально запускаемый бэкенд с API, постоянным хранением данных и аутентификацией единственного владельца.
- Синхронизировать одну реальную настройку профиля между устройствами при наличии сети и показывать состояние синхронизации.
- Заложить контракт для отдельных модулей активностей с собственными экранами, данными и настройками.
- Подготовить локальный сценарий запуска и проверки полного пути «Android ↔ сервер ↔ macOS».

Публикация сервера, полноценные функции чтения, программирования, домашних дел, английского и настроения, а также автономное редактирование с последующей отправкой изменений входят в следующие этапы.

## Capabilities

### New Capabilities

- `account-access`: вход и выход для единственного владельца, сохранение сессии на нескольких устройствах.
- `cross-platform-shell`: устанавливаемый клиент для Android и macOS, защищённая навигация и экран профиля.
- `profile-sync`: сохранение и синхронизация настройки профиля между устройствами при наличии сети.
- `activity-modules`: единый способ подключения независимых модулей активностей к приложению и API.

### Modified Capabilities

Нет.

## Impact

Появятся клиентское приложение, серверное API, база данных, локальная конфигурация разработки и документация запуска. Проект пока содержит только README и OpenSpec, поэтому существующее поведение не меняется.
